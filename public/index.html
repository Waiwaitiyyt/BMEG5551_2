Backend connection settings

Served through the Express gateway (server/ts, port 3000), the page posts the image to POST /api/predict (multipart form field file). Express proxies that to the FastAPI inference server on port 8000, which returns JSON bounding boxes. Override the target with API_BASE_URL at the top of app.js.

Prototype for educational purposes only — not intended for clinical use.
